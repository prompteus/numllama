# Numllama

This is the official repository for the EMNLP 2025 paper: **Pre-trained Language Models Learn Remarkably Accurate Representations of Numbers.**

## Set up env

```shell
git clone ...
cd ...
conda create -n numllama python=3.12
conda activate numllama
pip install poetry
poetry install
```
